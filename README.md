# Meus Pets — Acompanhamento

Site pessoal para cadastrar pets e manter histórico de saúde e consultas.

## Como usar
1. Abra `index.html` no navegador.
2. Cadastre os pets.
3. Use **Prontuário** para registrar ocorrências de saúde e consultas.
4. Os dados ficam no `localStorage` do navegador.
5. Use **Exportar** para fazer backup em JSON e **Importar** para restaurar.

## GitHub Pages
Envie `index.html`, `style.css` e `script.js` para um repositório público/privado e ative o GitHub Pages. O site não precisa de servidor ou banco de dados externo.

> Os registros são armazenados localmente no navegador. O backup JSON é recomendado para evitar perda de dados ao trocar de navegador/dispositivo.
